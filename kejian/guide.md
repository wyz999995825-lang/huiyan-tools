# 有声动画制作说明书：把孩子的英文阅读理解，做成一部会说话的动画片

> 分享人：吴燕子（3J&妈咪）｜《看得见的阅读》分享课配套材料
>
> **用法：** 把这份文件**整份**发给你的 AI 助手（Claude、ChatGPT、Gemini、豆包、Kimi 都可以），然后对它说：
> **「请按这份说明书，带我一步一步把孩子的阅读理解做成有声动画。先从第 0 步开始问我。」**

## 我为什么做这件事

一篇阅读理解，孩子看了半小时，还纹丝不动。我们从「再读一遍」说到「你怎么又错了」，最后孩子委屈得直掉眼泪，我们气得暴跳如雷——题，还是不会。

**不是孩子笨，也不是我们不够耐心——可能，只是方法不对。** 我们一直在逼孩子「读懂文字」，却没人帮他「看见故事」。

同一个故事，让孩子读文字，读完常常说不出来；可是动画片里的情节，他能绘声绘色讲给你听。所以我的顺序是：

> **先看得见，再听得懂，最后才记得住。**

起点是慧眼家长营上，小菜叔叔的《心的尺度》：一个心理学理论，被做成了动画，我一眼就看懂了，到现在都记得。我当时就想：如果孩子的阅读理解，也能做得这样一眼秒懂、铭记于心，那该多好。下课后，我把小菜叔叔给的制作方法原原本本交给 AI，让它拆解里面的套路，再把女儿真实的阅读理解卷发给它——第一部动画就这样开始了。

## 给 AI 的指令（AI 请先读这一部分）

你现在是一位「有声动画制作导演」，要带着一位**不会写代码**的家长，把孩子学校的一篇英文阅读理解，做成一部 3–6 分钟的有声动画片，片尾接一段带语音讲解的互动答题。请严格遵守：

1. **先学，再想，最后才做。** 动手前先读完这份说明书，尤其是「我定下的规矩」；然后给家长一页「创意说明」（第 1 步），家长同意了才开始做。
2. **一步一步来。** 按第 0–10 步推进。每一步先用一两句话说「这一步做什么、为什么」，再给可以直接复制的提示词或操作步骤，等家长把结果发回来，检查合格后再进下一步。不要一次把所有步骤倒出来。
3. **两个确认点不能跳过：** 旁白稿（第 2 步）和分镜（第 6 步），必须家长看过说 OK，才往下做。
4. **原文一个字都不改。** 旁白读的就是试卷原文。笑点、泪点、可爱的细节只放进画面，不改文字。
5. **题目的干扰项绝不能出现在画面里。**
6. **解析必须回到原文：** 每道题都要指出「答案在第几段、哪一句」，标出关键词。
7. **说人话。** 家长不懂技术，不要用术语；必须用时，用一句大白话解释。
8. **诚实。** 哪里要花钱、哪个效果做不到（比如对口型），提前说清楚，由家长决定，不替家长花钱，也不催。
9. **每一步交付前自己先检查一遍**，按「发片前检查清单」逐条对；每一步结束时用一行告诉家长：「这一步完成了 ✓，下一步是……」。
10. 下面「我定下的规矩」里的每一条，都是默认要求，家长不用再说一遍。

## 我定下的规矩（逐条清单）

这些都是我做 6 部片子时，一条一条和 AI 磨出来的。AI 请全部当作默认要求。

### 一、内容

1. 素材用孩子**真实的学校阅读理解原卷**，题目也用原卷的题目。
2. 旁白**一字不差读原文**，不改事实、不改情节。
3. 小朋友喜欢**幽默搞笑、有泪点感动**的情节——这些只放在画面里（骆驼探头抢镜、帽子被风吹飞、三个女孩抱在一起喜极而泣）。
4. **不制造焦虑：** 画面和讲解里不出现「你怎么又错了」的语气；孩子答错，动画永远温柔地带他回原文。
5. 片长通常 **3–5 分钟**；语速要适合孩子的年级（给低年级的要更慢）。

### 二、声音（声音是动画的灵魂）

6. **一定要有声音。** 不要做静音版。
7. 英语一律用**英式伦敦音**，像 BBC 的睡前故事，地道。
8. **旁白**：温柔、有感情，像情感类电台主播在讲故事，不要播新闻的腔调。
9. **不同的人用不同的声音：** 大人用大人的声音，男孩用男孩的声音，女孩用女孩的声音——故事里爸爸说话就用爸爸的声音，小女孩说话就用小女孩的声音，这样才生动。
10. **孩子的配音不能有鼻音，**要温柔，像动画片的配音，男孩女孩都要有代入感；不要捏着嗓子，不要夸张表演。
11. **每段多录几条，挑最好的。** 读错一个词就重来。
12. 机器检查只是初筛，**最后一关一定是大人自己戴耳机听一遍。**

### 三、音乐

13. 只用**免版权**的纯音乐（没有人声）；不用迪士尼、宫崎骏电影的原声，可以找风格相近的原创曲。
14. 我喜欢的风格：**简单干净、治愈的；也要有童趣的；宫崎骏那种干净的感觉**；同时要**有感染力**。
15. 背景音乐**始终压低**，绝不能盖住讲故事的声音；有人说话时再压低一点。
16. **慢入慢出：** 开头淡入，结尾慢慢淡出。
17. 音乐比片子短时**自动循环**到片子结束，循环接缝要听不出来——**绝不能片子没完，音乐先停了。**

### 四、画面

18. **必须是动画片，不是会动的绘本。** 一张静止的图加一点镜头推拉、人物轻轻晃一晃，那叫幻灯片。每个镜头里的人物都要真的在动：走、跑、扇风、拥抱、挥手、表情变化。
19. **要换画面：** 不要一个画面从头放到尾，大约每一两句话换一个镜头。
20. 画风：我选的是**精致的 3D 动画风格**（像迪士尼、皮克斯），人物衣品要高大上，不要 low；环境要精致；不要写实，也不要 AI 味很重的那种。
21. **对口型：** 人物说话时，嘴要跟着说的话动；不说话时嘴闭着或在微笑。不对口型「很怪」。
22. **比例要真：** 人不能比汽车还大。
23. **表情要和文字一致：** 文字说 frightening（害怕），脸就不能在笑——否则等于教错了单词的意思。
24. **造型要美：** 丑一帧，孩子就出戏。例：女孩鼓着嘴扇风，像在生气，就要重做。
25. **题目的干扰项绝不能出现在画面里**（例：题目里有「沙子太多」这个错误选项，画面就不要特意拍漫天风沙；没人骑骆驼的地方就不要画人骑骆驼）。
26. **封面**要选一个有趣的画面，不要一面白墙那种。

### 五、互动答题（最重要的一步）

27. **孩子自己点选答案。** 点完不要直接给答案——先给提示，让孩子再想想。**给孩子搭梯子，而不是直接给答案。**
28. 答题设计是**循序渐进**的：
    - 第一次出错：帮他**排除错误选项**（说清这个选项为什么不对，但不说哪个对），再带他回原文那一段；
    - 第二次：**拆解核心生词**，缩小范围；
    - 第三次：**一起梳理出答案**；
    - 答对了：也要**再次点明原文依据**。
29. **解析不能只说「为什么」，要指给孩子看：答案在原文哪一句。** 第几段、哪一句、哪个关键词（比如 However 后面的那一句），把句子标黄、把关键词圈出来。
30. 答错时，**直接把故事里那一段再播一次**（小画面 + 原句 + 线索词标黄），带孩子回忆，不要只说「你回去再看看」。
31. **必须有真正的语音讲解。** 我不喜欢「没有语音、只让孩子自己回去看」的答题方式，孩子会一头雾水。
32. 题目一出现就**自动读题**，读到哪个选项，哪个选项亮；每个选项旁边有小喇叭，可以单独再听。
33. **屏幕上的字要和语音说的一字不差。**
34. 讲解也用不同的声音，和故事里一样生动。
35. **计分不乱夸：** 一次答对 3 颗星，第二次 2 颗，第三次 1 颗，讲出来的 0 颗；结尾按实际星数给评语。
36. 每题下面列出难词，点一下出英文解释 + 中文意思。
37. **视频版也要有答题讲解**，接在故事后面，带讲解配音。

> **我们教的不是一道题，是一辈子都能用的、寻找证据的阅读思维。**

### 六、交付和分享

38. 要**跨设备、跨网络**都能看：手机、iPad、电脑都要自适应。
39. 最好给**可下载的视频**（能直接发朋友圈、视频号、小红书）——光给链接，很多人不愿意点。
40. 做工具就**一个入口**，不要散落一堆网页和文件。
41. 成品统一存进一个文件夹；**做完把中间的临时文件清掉。**

### 七、做事的方法

42. **先学再想再做。** 动手前先看好的作品（我看的是小菜叔叔的《心的尺度》和三国绘本《草船借箭》），想清楚再做。
43. **别自己闷头做，问问孩子想看什么——孩子，才是我们最好的产品经理。** 我女儿一句「妈妈，我喜欢迪士尼那样的动画片」，让我的画面上了一个台阶。
44. **做完先给 5 个小朋友看**（不同年龄、男孩女孩都有），听他们的意见改一轮，再发。
45. 做完别急着发：**一帧一帧看，像孩子那样挑刺。**
46. **工具会过时，流程不会：** 先想清楚孩子会在哪一秒笑，再去选工具。

## 总流程一览

0. 准备素材 → 1. 读懂孩子 + 创意说明 → 2. 旁白稿（**确认点**）→ 3. 选声音 → 4. 生成配音 → 5. 选配乐 → 6. 分镜和画面（**确认点**）→ 7. 让画面动起来 → 8. 互动答题和解析 → 9. 拼成一部片 → 10. 找 5 个小朋友试看

前面几步是「准备」，后面是「让孩子爱上」。**第一部别追求完美：做出来、给孩子看、听他的意见，比什么都重要。**

## 第 0 步 · 准备素材

**家长做：**

1. 把阅读理解原文、题目、标准答案平铺拍清楚：每页一张，不要歪斜、不要反光、不要切掉边。
2. 发给 AI，附上这段话：

```
这是我孩子的英文阅读理解原卷（原文 + 题目 + 答案）。
请先把原文一字不差地转成文字，按段落编号（第 1 段、第 2 段……）；
再把每道题和四个选项、正确答案整理成表格。
有看不清的字，请标出来问我，不要自己猜。
```

**AI 检查：** 逐段核对转写，和家长确认没有错字。这份文字就是后面所有步骤的「底稿」。

---

## 第 1 步 · 读懂孩子，写创意说明

动画是做给**这一个孩子**看的。

**1.1 AI 先问家长（家长也可以直接回答）：**

```
1. 孩子几岁、几年级？英语大概什么水平？
2. 孩子平时最爱看什么动画？（迪士尼？皮克斯？小猪佩奇？）
3. 孩子容易在哪类题上丢分？（找原文依据？生词？推断人物心情？）
4. 孩子喜欢什么样的笑点？（动物抢镜、帽子被风吹飞、有人摔个屁股墩……）
5. 看完这部片，你最希望孩子带走什么？
```

**1.2 让 AI 写一页「创意说明」（先不做任何东西）：**

```
请先不要动手做，先给我一页创意说明：
- 一句话说清这部片的核心（一句话说不清就重想）。
- 故事分几段，每段讲什么、在什么场景。
- 每段里，孩子会在哪一秒笑、哪一秒被打动（写出具体画面）。
- 画风、主色调、配乐风格（每段用什么情绪的音乐）。
- 这篇阅读理解的考点（主旨、人物心情、关键词句）藏在哪个画面里。
- 每道题的干扰项是什么——这些东西画面里都不能出现。
- 这一版能做到什么、做不到什么（例如能不能对口型），提前说清楚。
```

家长看过、同意了，再往下。

---

## 第 2 步 · 旁白稿（确认点）

**发给 AI：**

```
请把原文做成「旁白稿」：
- 原文一个字都不改，按句子切开，每行一句。
- 标出每一句由谁来读：旁白（Narrator），或者故事里的某个人物（引号里的话由那个人物来说）。
- 给每个角色写一句声音设定：性别、大概年龄、性格。大人用大人的声音，男孩用男孩的声音，女孩用女孩的声音。
- 列出孩子可能不认识的生词（不超过 8 个），每个给英文解释 + 中文意思。
最后用表格给我看。
```

**家长检查：** 有没有漏句、角色分得对不对、生词选得合不合适。确认 OK 再往下。

---

## 第 3 步 · 选声音

画面再好看，声音不对，孩子三秒就走神。

**家长做：**

1. 打开 **aistudio.google.com**，用 Google 账号登录。
2. 找到 **语音生成（Generate speech）**。
3. 选声音（Voice）。我常用的：
   - 旁白：**Sulafat、Achernar**（温柔、娓娓道来）
   - 女孩：**Aoede、Leda、Despina**
   - 男孩：**Puck、Zephyr**
4. 在「风格说明（Style instructions）」里写清口音和语气。

旁白：

```
Read in a warm, gentle British (London) accent, like a BBC bedtime story narrator.
Calm pace, short pauses between sentences. Emotional but natural, not dramatic.
British English, not American.
```

女孩（年龄按故事改）：

```
Speak like a cheerful 10-year-old British girl in an animated film.
Sweet, clear and soft, no nasal tone, natural, not over-acted, not squeaky.
British (London) accent. Slow pace, small pause between sentences.
```

男孩：

```
Speak like a bright 10-year-old British boy in an animated film.
Clear, round and clean voice, no nasal tone, natural, not over-acted.
British (London) accent. Slow pace, small pause between sentences.
```

大人（例如向导、爸爸）：

```
Speak like a friendly British man in his 40s, warm and calm, London accent, natural, not dramatic.
```

5. 先用一两句试听，选出满意的声音再批量做。

**为什么风格说明这么重要：** 孩子的声音要有「代入感」，主要就靠这一句。每个角色在这一句话里是什么情绪（开心、累、害怕、惊喜），也可以写进去，例如「she is exhausted and hot, then excited when she sees the sunrise」。

**小提醒：**

- 风格说明一定写在「风格」那一栏，不要写进正文，否则 AI 会把它念出来。
- 如果读成了美式口音：换一个更正式的模型（别选标着 lite / 快速的那种，我遇到过快速版跑成美音），或者在风格里加「British, not American」。
- 免费版每个模型**每天有次数上限**（我实测大约每天 10 次左右，以官网为准）。一部片子十几段，可以分两天做，先做最重要的段落。

## 第 4 步 · 生成配音，再听一遍

**家长做：**

1. 按旁白稿一段一段生成。**每段多生成 2–3 条**，挑最好的一条。
2. 下载下来，按顺序命名：`01_narrator.wav`、`02_gwen.wav`……
3. **戴上耳机听一遍。** 重点听：
   - 有没有读错、漏读、多读的词
   - 有没有杂音、爆音
   - 有没有把风格说明念出来
   - 是不是英式口音
   - 孩子的声音有没有鼻音、是不是太夸张

**可以先让 AI 帮你初筛（能上传音频的 AI 都可以）：**

```
请仔细听这段配音，对照下面的原文逐字转写，告诉我：
1. 有没有读错、漏读、多读的词？（特别注意：【列出难读的词】）
2. 有没有杂音、爆音、突然的音量变化？
3. 是不是英式口音？
4. 有没有把开头的风格说明念出来？
原文：【粘贴这一段原文】
```

> 我踩过的坑：单词 **waded**（蹚水），机器第一次读成了 **waited**（等待）。一个音之差，意思全变了。所以机器只是初筛，**最后一关一定是我们大人自己的耳朵。**

---

## 第 5 步 · 选配乐

**去哪里找：**

- Free Music Archive 上标着 **CC0** 的曲子（例如 HoliznaCC0 的作品）
- OpenGameArt 上标着 CC0 的音乐
- YouTube 音频库、Pixabay 音乐

下载前看清授权说明。**不要用迪士尼、宫崎骏电影的原声**——有版权，可以找「风格相近」的原创曲。

**怎么选：**

- 治愈、干净、带一点童趣；整体要有感染力。
- 按每一段的情绪配：安静叙述、开心、紧张、感动，可以换不同的曲子。
- 选纯器乐，不要有人声、合唱，最好也不要鼓点太重的。

**拼片时的规矩（第 9 步要用）：**

1. **音乐始终压低**，有人说话时再压低一点，绝不能盖住讲故事的声音。
2. **慢入慢出：** 开头 2–3 秒淡入，结尾 4–5 秒淡出。
3. 音乐比片子短就**循环**，接缝做个交叉淡化，不能出现片子没完音乐先停。

---

## 第 6 步 · 分镜和画面（确认点）

### 6.1 让 AI 写分镜

```
请按旁白稿，帮我写分镜表。格式：镜头号 / 对应的旁白句子 / 画面里有谁、在哪、在做什么 / 表情 / 笑点或泪点。
要求：
- 大约每 1–2 句旁白换一个镜头，全片 15–25 个镜头。
- 每个镜头里的人物都要在做一个具体动作（走、跑、扇风、拥抱、拍照），不要站着不动。
- 人物表情必须和文字一致：文字说害怕，脸就要害怕，不能在笑。
- 比例要真实：人不能比汽车还大。
- 旁白在讲的镜头，人物嘴巴闭着或微笑；人物说引号里的话时，标出来。
- 题目里的错误选项绝不能出现在画面里。请先把每道题的干扰项列出来，再逐个镜头检查。
- 每个镜头写一条 Canva AI 出图的英文提示词（要求见下面 6.2）。
- 最后单独选一个最有趣的画面当封面（不要白墙）。
```

**家长检查分镜，确认 OK 再出图。**

### 6.2 在 Canva AI 出图

1. 打开 Canva → **Canva AI**。**一部作品用一个对话**，不要中途换对话，否则人物会「换脸」。
2. **先出「定妆照」**：每个角色一张，浅灰底，3–4 个姿势。以后所有画面都照这个长相和衣服画。

```
Character sheet for a 3D animated film, Disney/Pixar-like style, polished and premium.
Character: Gwen, 11-year-old girl, shoulder-length brown hair, light beige safari shirt,
khaki shorts, white sneakers, sun hat. Show 4 poses: standing, walking, fanning herself,
laughing. Plain light grey background. No text.
```

3. **再按分镜一张一张出画面。** 每条提示词都把每个人物的长相和衣服**完整写一遍**——不要只写「参考上面的 Gwen」，对话一长，Canva 就找不到，会不出图或画错人。每条结尾统一加：

```
Same 3D animated style, only the characters mentioned, main action in the centre of the frame,
16:9, no text, no logos.
```

4. **出完一张，先自己挑一遍：** 比例对不对、表情对不对、造型美不美、有没有画进干扰项、有没有怪手怪脚。不对就让它重画，并说清哪里不对。

## 第 7 步 · 让画面真正动起来

一张图在那推来推去，那叫幻灯片，不叫动画片。这一步是我踩过最大的坑：第一版就是静止的图加镜头推拉，我自己看完都觉得「这不就是幻灯片吗？」

**家长做：**

1. 在**同一个** Canva AI 对话里，用「图片变视频（Image to Video）」把每张画面变成约 6 秒会动的小视频（无声）。
2. 提示词写清**谁在做什么动作**，并把笑点、泪点写进去：

```
Please make a short animated video clip from page 12 with Image to Video:
the girls fan themselves wearily, one hat flies off in the wind and she chases it.
Keep exactly the same characters, faces, outfits, colours and 3D style. No text.
Lips closed, not talking.
```

**几个实用技巧（我自己摸出来的）：**

- 用**页码**告诉 Canva 是哪一张图，只写图的名字它常常认不出来。注意：**页码是倒着排的**，最新出的那张是第 1 页。先点开一张图，看看它在编辑器里是第几页，再推算其他的。
- 一条消息可以一次要好几段（我试过最多 6 段），超过它会问「是否继续」，回答「继续」就行。
- 每一段都要写「Keep exactly the same characters, faces, outfits, colours and 3D style」，不然人物会变。

**关于嘴巴（很重要）：**

- 旁白在讲的镜头，提示词一定加 **「lips closed, not talking」**。不要写 talks / chats / says / calls，否则人物会对着空气乱动嘴，很怪。
- 人物说引号里的话时，「图片变视频」对不准你的配音。可以用**背影、远景、侧脸**来避开。真要对口型，得用专门的口型同步工具，一般要花钱，自己决定。

**额度：** 图片变视频会消耗 Canva 的 AI 额度。我实测每段大约用掉当月额度的 2–3%，一部片 15–25 段，先在 Canva 的「设置 → 账单/用量」里看看够不够，不够就先做最关键的镜头。

## 第 8 步 · 互动答题和解析（最重要的一步）

很多讲解只告诉孩子「为什么选这个」，孩子听完点头说懂了，下次换一篇，照样错。**解析不能只说「为什么」，要指给孩子看：答案在原文哪一句。** 这跟小菜叔叔课上讲的一模一样：阅读理解，答案要回原文找线索、划线。

### 8.1 答题的四级梯子

| 孩子的情况 | 动画怎么回应 |
|---|---|
| 第一次答错 | 温柔地说**这个选项为什么不对**（不透露哪个对），帮他**排除错误选项**；然后说「我们回到第 X 段找找看」，直接把故事里那一段再播一次，原句标黄 |
| 第二次答错 | **拆解核心生词**（英文解释 + 中文意思），缩小范围，再选 |
| 第三次答错 | 和他**一起梳理出答案**，一句一句讲 |
| 答对了 | 也要**再次点明原文依据**：第几段、哪一句、哪个关键词 |

**一个真实的例子（Sunrise in the Sahara 第 2 题）：**

- 题目：What was the problem encountered by Gwen and her friends in paragraph 2?
- 孩子选了 (1)「There was too much sand」。动画不会说「你错了」，而是温柔地说：「沙子确实很多，可第 2 段没说沙子是麻烦哦。我们回原文找找看！」
- 然后带他回到第 2 段，先圈出 **However**——问题常常藏在 however 后面；再把 **nothing could prepare them for the scorching heat** 这一句划出来。
- 孩子自己就找到了答案 (2)：They felt the weather was unbearably hot。
- 答对后再说一遍：「对了！scorching heat = 热得受不了，这就是他们的麻烦。出处：第 2 段，However 后面这一句。」

### 8.2 让 AI 写讲解稿

```
请为每道题写「答题讲解稿」，严格按四级梯子：
1. 第一次答错：针对孩子选的那个错误选项，用一两句话说明为什么不对（不透露正确答案），
   然后说「我们回到第 X 段找找看」。每个错误选项各写一版。
2. 第二次答错：解释这道题的 1–2 个核心生词（英文 + 中文），缩小范围。
3. 第三次答错：和孩子一起把答案讲出来。
4. 答对了：说出答案 + 原文依据（第几段、原句、需要圈出的关键词，比如 However）。
另外：
- 读题稿：题干和四个选项各一句，用于自动读题。
- 每道题列出原文出处句子、要标黄的句子、要圈出的关键词、对应故事里的哪个镜头。
- 每题列 2–3 个难词：英文解释 + 中文意思。
语言用简单英文（适合【几年级】），每条不超过 3 句；附中文翻译给家长看。
屏幕上显示的字必须和语音一字不差。
```

### 8.3 给讲解配音

用第 3–4 步同样的方法配音。讲解可以用旁白的声音，也可以请故事里的人物来讲，更生动。

> **我们教的不是一道题，是一辈子都能用的、寻找证据的阅读思维。**

## 第 9 步 · 拼成一部片

两条路，选一条。

### 路线 A：简单版——做成视频（推荐第一次用）

用**剪映 / CapCut** 或 **Canva 视频编辑器**：

1. 按分镜顺序把小视频片段排好。片段太短时可以稍微放慢，不要一张图硬撑很久。
2. 配音轨对齐：每句话出现时，画面正好是那个镜头。
3. 加字幕：字幕就是原文，生词可以换个颜色高亮。
4. 加配乐：压低音量；人说话时再压低；开头淡入、结尾淡出；不够长就循环。
5. 片尾接答题讲解：题目画面 → 讲解配音 → 回到原文那一段的画面，原句高亮、关键词圈出。
6. 封面用你选的最有趣的那个画面。
7. 导出 **1080p MP4**——可以直接发朋友圈、视频号、小红书。

### 路线 B：进阶版——做成会互动的网页（孩子可以自己点选答案）

把下面这段发给 AI（Claude 做这件事很擅长）：

```
请帮我做一个单文件 HTML 的有声动画网页，手机、iPad、电脑都能自适应打开：
- 素材：【视频片段】【每句配音】【配乐】【旁白稿】【读题稿、答题讲解稿和讲解配音】
- 故事部分：按顺序播放片段，字幕和配音同步；音乐压低、人说话时再压低、慢入慢出、不够长就无缝循环。
- 答题部分：
  · 题目出现时自动读题，读到哪个选项哪个亮；每个选项旁有小喇叭可以再听；孩子随时可以点选。
  · 按「四级梯子」回应：第一次错排除选项并在答题卡里直接播放原文那一段、关键句标黄；
    第二次错拆生词；第三次一起讲出答案；答对也要讲原文依据。
  · 屏幕上的字和语音一字不差。
  · 一次答对 3 星、第二次 2 星、第三次 1 星、讲出来 0 星，结尾按实际星数给评语，不乱夸。
  · 每题下面列难词，点一下出英文解释和中文意思。
- 声音必须由孩子点「开始」后才播放（手机浏览器的规定）。
- 所有素材打包进一个文件，双击就能打开。
请先告诉我你需要我提供哪些文件、怎么命名，再开始做。
```

## 第 10 步 · 发之前，先给 5 个小朋友看

找 5 个不同年龄、男孩女孩都有的小朋友看一遍，听他们说哪里好笑、哪里看不懂、答题卡在哪里。找不到真人时，也可以先让 AI 扮演：

```
请分别扮演 5 个小朋友：P1 女孩、P2 女孩、P3 男孩、P5 男孩，再加一位陪学龄前孩子的家长。
看完下面这部动画的分镜和答题设计后，每人说：
哪一秒你笑了、哪一秒你走神了、哪里没看懂、答题时卡在哪里、最想改哪一处。
【粘贴分镜表和答题讲解稿】
```

听完意见，改一轮，再发。AI 扮演只是参考，**真孩子的反应最准**。

## 我踩过的坑

| 坑 | 后来怎么做 |
|---|---|
| 第一版是一张静止的图加镜头推拉，像幻灯片 | 每个镜头都用「图片变视频」做成真的会动的小视频 |
| 一个画面从头放到尾，很死板 | 每 1–2 句话换一个镜头 |
| 画面是代码画的简单卡通，女儿说想要迪士尼那样的 | 改用 Canva 出精致 3D 画面——问孩子想看什么 |
| 女孩鼓着嘴扇风，看起来像在生气 | 重做成自然微笑；做完一帧一帧挑刺 |
| 有一版人画得比汽车还大 | 分镜里写清比例，出图后先自己检查 |
| 人物说 frightening 时脸却在笑 | 表情必须和文字一致，否则教错单词 |
| 旁白在讲，画面里的人却在动嘴 | 提示词加「lips closed, not talking」 |
| waded 被读成 waited | 每段多录几条，机器先查，大人戴耳机最后把关 |
| 快速版的语音模型跑成了美音 | 用正式版模型，风格里写「British, not American」 |
| 风格说明被 AI 念了出来 | 风格写在「风格」那一栏，不写进正文 |
| 音乐比片子短，片子没完音乐先停了 | 音乐自动循环，结尾慢慢淡出 |
| 答题只让孩子「自己回去看」，孩子一头雾水 | 必须有语音讲解，直接把那一段原文再播一次 |
| 解析只说「为什么」，孩子换一篇照样错 | 指出原文第几段、哪一句，标黄、圈关键词 |
| 只写图片名字，Canva 认不出是哪张 | 用页码（倒序，最新的是第 1 页） |
| 对话太长，Canva 不出图 | 每条提示词都把人物长相衣服完整写一遍 |
| 只发链接，很多人不愿意点 | 同时导出 MP4，能直接发朋友圈 |

## 发片前检查清单

**画面**

- [ ] 每个镜头人物都在真的动，不是静止图
- [ ] **比例要真**：人不能比汽车还大
- [ ] **嘴要对上**：谁说话谁动嘴，不说话就闭上
- [ ] **造型要美**：没有怪手、怪脸、丑的一帧
- [ ] **表情和文字一致**
- [ ] 题目的**干扰项没有出现在画面里**
- [ ] 封面是有趣的画面

**声音**

- [ ] 原文一个字没改，没有读错的单词
- [ ] 英式口音，大人、男孩、女孩各用各的声音
- [ ] 孩子声音没有鼻音、不夸张
- [ ] 音乐没有盖住人声；结尾慢慢淡出，不是突然停；不够长时循环了

**答题**

- [ ] 孩子自己点选，不直接给答案
- [ ] 四级梯子都有，每一级都有语音
- [ ] 每题都指出原文第几段、哪一句，标黄、圈关键词
- [ ] 屏幕上的字和语音一字不差

**分享**

- [ ] 手机、iPad、电脑都能正常打开
- [ ] 导出了可以直接发朋友圈的 MP4
- [ ] 给 5 个小朋友看过，按意见改过一轮

## 常见问题

**Q：我完全不会编程，能做吗？**
能。我也不会。我做的，就是把想要什么**清清楚楚**告诉 AI：这个镜头谁在干什么、什么表情、哪里不对。你不需要会写代码，只需要会「说清楚」。

**Q：做一部要多久？**
第一部可能要几个晚上；熟练以后，一篇阅读理解大概一两个晚上。

**Q：要花多少钱？**
配音（Google AI Studio）和配乐可以免费；画面「图片变视频」需要 Canva Pro（有免费试用）。花不花，你自己决定。

**Q：AI 给的东西不满意怎么办？**
直接说哪里不对，越具体越好。例如：「第 7 个镜头，女孩的嘴在动，但这时候是旁白在讲，请让她闭嘴微笑。」「第 3 段第 2 句，waded 读成了 waited，请重新生成。」

**Q：孩子还小，看得懂英文吗？**
先看画面、听声音，再看字。动画的作用就是让孩子先「看见故事」，再「读懂文字」。片长和语速按孩子的年级调。
